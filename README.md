# Kuliberda Labs

Open-source tools for video, motion, and AI-agent workflows.

Small, sharp utilities for people who make content at scale — programmatic video,
montage, render quality-control, and the tooling around directing AI agents to do real work.
Original code, MIT-licensed, runs locally.
